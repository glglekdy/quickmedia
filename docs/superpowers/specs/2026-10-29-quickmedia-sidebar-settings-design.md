# QuickMedia: 왼쪽 메뉴와 설정 화면 설계

작성일: 2026-10-29
범위: 데스크톱 화면 개편의 첫 작업. 개편은 ① 왼쪽 메뉴 + 설정 화면(이 문서) → ② 업데이트 화면 → ③ 다운로드 화면 다듬기 순서로 하고, ②·③은 따로 설계한다.
시안: [`2026-10-29-quickmedia-sidebar-settings-mockup.html`](2026-10-29-quickmedia-sidebar-settings-mockup.html) (브라우저로 열면 메뉴와 설정 칸을 눌러 볼 수 있다)

## 목표

- 설정을 카테고리로 나눠 원하는 항목을 빨리 찾게 한다.
- 설정을 새 창으로 띄우지 않고 메인 창 안에서 연다.
- 메인 창 왼쪽에 늘 보이는 메뉴를 둔다: **다운로드**, **설정**(누르면 아래로 펼쳐져 로그인 · 네트워크 · 파일 · 고급).
- 설정은 바꾸면 바로 저장한다. [취소] [저장] 버튼은 없앤다.

## 하지 않는 것

- 업데이트 메뉴와 화면(②). 이번 작업이 끝나도 업데이트 창은 지금처럼 따로 뜬다. `ytdl/update_dialog.py`는 건드리지 않는다.
- 다운로드 화면 다듬기(③). 오른쪽 위 ⚙ 버튼만 뺀다.
- 색·글꼴·버튼 모양 바꾸기. `theme.py`의 색 토큰을 그대로 쓰고, 메뉴와 설정 화면에 필요한 스타일만 더한다.
- 설정 항목을 더하거나 빼기, 검사 규칙 바꾸기.
- 화면 전환 애니메이션, 키보드로 메뉴 옮겨 다니기, 설정 검색.
- 버전 올리기와 릴리스. ①~③이 끝난 뒤 정한다.

## 화면

### 창

- 기본 크기 **800 × 680**, 최소 **690 × 480** (지금 640 × 680, 최소 520 × 480). 오른쪽 내용 폭은 지금과 거의 같다.
- 가운데는 `[왼쪽 메뉴 168px | 화면 묶음(QStackedWidget)]`.

### 왼쪽 메뉴

```
 ⤓  다운로드
 ⚙  설정        ›    ← 누르면 아래로 펼쳐지고 › 가 아래를 향해 돈다
      로그인
      네트워크
      파일
      고급
```

- 메뉴 바탕 `surface`, 오른쪽에 1px `border` 선. 안쪽 여백 12px 8px.
- 항목: 높이 34px, 둥근 모서리 6px, 아이콘 16px(회색 선 그림 `download.svg`, `gear.svg`), 글자 13px(보통 500).
- 선택된 항목: 바탕 `btn_bg`, 글자 600, 왼쪽에 `accent` 빨간 세로 막대(폭 3px, 위아래 9px 띄움, 끝이 둥긂).
- 마우스를 올린 항목: 바탕 `nav_hover`(새 토큰. 라이트 `#f0f0f0`, 다크 `#232323`).
- 하위 항목(로그인 등)은 아이콘 없이 글자를 '설정' 글자 위치에 맞춰 들여 쓴다.
- 화살표(›)는 `muted` 색 선 두 개로 그린다.

| 상황 | 결과 |
|---|---|
| 앱을 켬 | '다운로드' 선택, '설정' 접힘 |
| 접힌 '설정'을 누름 | 0.2초(OutCubic) 동안 아래로 펼치고 화살표를 90° 돌린다. 설정 화면을 보던 중이었으면(접어 둔 상태) 그 화면을 그대로 두고, 아니면 '로그인' 화면을 연다 |
| 펼친 '설정'을 누름 | 접기만 한다. 화면은 그대로. 설정 화면을 보는 중이면 '설정' 항목에 선택 표시 |
| 카테고리를 누름 | 그 화면으로 바꾼다 |
| '다운로드'를 누름 | 다운로드 화면으로 바꾸고 '설정'을 저절로 접는다(같은 애니메이션) |
| 지금 보고 있는 항목을 누름 | 아무 일도 없다 |

화면 사이는 애니메이션 없이 바로 바뀐다.

### 다운로드 화면

지금 메인 창 내용 그대로다(헤더, 링크 칸, 형식 줄, 세부 옵션 패널, 다운로드 목록, 저장 위치 독). 헤더 오른쪽의 ⚙ 버튼만 없앤다. 제목 `QuickMedia`와 안내 문구도 그대로 둔다.

### 설정 화면 공통

```
 네트워크  ✓ 저장했어요                      ← 제목 22px(#crumb). 저장 표시는 1.5초만
 인터넷 연결과 받는 속도에 관한 설정이에요.     ← 설명 12px muted (#viewHint)
 ┌──────────────────────────────────────────┐
 │ 프록시         [http://127.0.0.1:8080    ] │  ← 카드: card_bg, 1px border, 둥근 10px, 안쪽 18px 20px
 │ 속도 제한      [예: 5M     ]               │
 │                비워 두면 제한 없이 받아요…  │  ← 안내 12px muted (#hint)
 │ 재시도 횟수    [10 ]                       │
 │ 동시 다운로드  [2  ]                       │
 │                한 번에 받는 영상 수 (1~5)   │
 └──────────────────────────────────────────┘
```

- 바깥 여백 24px 28px(다운로드 화면 헤더와 같은 자리). 제목과 설명 사이 4px, 설명과 카드 사이 16px.
- 줄: 이름 칸 112px(로그인 화면만 160px) + 입력 칸 최대 400px, 줄 간격 14px. 이름은 입력 칸 글자 높이에 맞춘다.
- 안내와 오류는 입력 칸 바로 아래. 오류는 `#fieldError` 빨간 글씨이고, 틀린 글자 칸은 테두리도 `danger` 색(새 스타일 `QLineEdit[invalid="true"]`).
- 저장 표시 `✓ 저장했어요`는 제목 오른쪽, `success` 색 12px(`#savedBadge`).
- 내용이 화면보다 길면 그 화면 안에서 세로로 스크롤한다.
- 켜고 끄는 규칙은 지금 설정 창과 같다(아래 화면별 설명).

### 설정 화면별 내용

**로그인** — 설명 `로그인해야 볼 수 있는 영상은 브라우저의 로그인 정보(쿠키)를 써서 받아요.`

- ( ) 사용 안 함
- ( ) 브라우저에서 가져오기 `[브라우저 목록]` — 안내 `Chrome·Edge 는 켜져 있으면 쿠키를 못 읽을 수 있어요`
- ( ) cookies.txt 파일 `[경로 칸] [찾기]` — 경로 칸 안내 글자 `파일을 고르세요`
- 브라우저 목록은 '브라우저에서 가져오기'일 때만, 경로 칸과 [찾기]는 'cookies.txt 파일'일 때만 켠다. 브라우저 목록 순서와 이름은 지금과 같다(Firefox 맨 위).

**네트워크** — 설명 `인터넷 연결과 받는 속도에 관한 설정이에요.`

- 프록시 — 안내 글자 `http://127.0.0.1:8080`
- 속도 제한 — 안내 글자 `예: 5M`, 안내 `비워 두면 제한 없이 받아요. 5M 은 초당 5MB`
- 재시도 횟수 — 숫자 칸 0~50
- 동시 다운로드 — 숫자 칸 1~5, 안내 `한 번에 받는 영상 수 (1~5)`

**파일** — 설명 `받은 파일의 이름을 어떻게 지을지 정해요.`

- 파일 이름 — 제목 / 제목 [ID] / 업로더 - 제목 / 날짜 제목 / 직접 입력
- 직접 입력 — '직접 입력'일 때만 켠다. 안내 `yt-dlp 출력 템플릿 문법을 써요`
- [ ] 같은 이름의 파일이 있으면 덮어쓰기 — 안내 `끄면 '제목 (1).mp4' 처럼 번호를 붙여 새로 받아요`

**고급** — 설명 `yt-dlp 명령줄 옵션을 그대로 넣어요. 다른 설정보다 우선해요.`

- yt-dlp 옵션 — 안내 글자 `예: --limit-rate 1M --no-mtime`

## 저장: 바꾸면 바로

| 칸 | 저장하는 때 |
|---|---|
| 라디오, 체크박스, 콤보박스, 숫자 칸 | 바꾸는 즉시 |
| 글자 칸(쿠키 경로, 프록시, 속도 제한, 직접 입력, yt-dlp 옵션) | Enter 를 치거나 다른 곳을 눌렀을 때(`editingFinished`) |
| 쿠키 [찾기] | 파일을 고른 즉시 |

- **묶인 칸은 같이 넘긴다.** 쿠키 방식을 'file'로 바꿀 때는 경로 칸 값도, 파일 이름을 '직접 입력'으로 바꿀 때는 직접 입력 칸 값도 같이 넘겨 함께 검사한다.
- **값이 실제로 바뀌었을 때만** 저장하고, 그 화면 제목 옆에 `✓ 저장했어요`를 1.5초 보인다. 1.5초 안에 또 저장하면 그때부터 다시 1.5초.
- **틀리면 저장하지 않는다.** 그 칸을 빨갛게 하고 아래에 지금과 같은 오류 문구를 띄운다. 고칠 때까지는 전에 저장된 값을 쓴다.
  - 예: 'cookies.txt 파일'을 골랐는데 경로가 없거나 파일이 없으면 `쿠키 파일을 찾을 수 없어요`. 쿠키 방식은 전에 쓰던 값 그대로다.
- **바꾼 칸 때문에 생긴 오류만 저장을 막는다.** 이미 저장된 다른 값이 지금은 틀려도(예: 저장해 둔 쿠키 파일이 지워짐) 다른 칸은 저장된다.
- 앱을 켤 때 이미 틀려 있는 저장값은 그 칸을 건드리기 전에는 표시하지 않는다. 지금 설정 창도 [저장]을 누르기 전에는 보여 주지 않았다.
- 맞는 값으로 고치면 그 칸의 오류 표시를 지운다. 고친 값이 저장된 값과 같아서 저장할 게 없어도 지운다.

### 설정 화면을 떠날 때

다른 메뉴로 가거나 창을 닫을 때, 보고 있던 설정 화면은 다음을 한다(`leave()`).

1. 아직 저장 안 된 글자 칸 가운데 맞는 값은 저장한다. 다른 곳을 누르지 않고 바로 메뉴를 눌러도 입력이 날아가지 않게.
2. 모든 칸을 저장된 값으로 다시 채우고 오류 표시를 지운다. 틀린 값은 여기서 버려진다. 'file'로 바꿨지만 저장되지 않은 쿠키 방식도 전 값으로 돌아간다.

### 저장되면

지금 설정 창에서 [저장]을 눌렀을 때와 같은 일을 한다.

- QSettings `settings/<필드>`에 쓴다.
- `JobQueue.set_limit(concurrency)`: 받는 중인 목록에 바로 적용된다.
- `SiteIcons.proxy = proxy`.
- 이미 대기열에 넣은 작업은 넣던 순간의 설정(`Snapshot`)으로 받는다. 지금과 같다.

### `update_settings(s, **fields) -> tuple[AppSettings, dict[str, str]]`

바꾼 칸을 넣은 새 설정과, **바꾼 칸이 원인인 오류만** 돌려준다. 오류가 있으면 새 설정 대신 `s`를 그대로 돌려준다.

1. `cand = dataclasses.replace(s, **fields)`
2. `validate_settings(cand)`의 오류 가운데 원인 필드가 `fields`에 있는 것만 남긴다.

| 오류 키 | 원인 필드 |
|---|---|
| `rate_limit` | `rate_limit` |
| `cookie_file` | `cookies`, `cookie_file` |
| `custom_template` | `name_template`, `custom_template` |
| `extra_args` | `extra_args` |

### `SettingsModel(QObject)`

- `value: AppSettings` — 지금 저장된 설정. 네 화면이 이것 하나를 같이 본다.
- `update(**fields) -> dict[str, str]` — `update_settings`를 부른다. 오류가 없고 값이 바뀌었으면 `value`를 바꾸고 `changed(AppSettings)` 신호를 낸다. 오류를 돌려준다.
- 메인 창은 `changed`를 받아 "저장되면"의 일을 하고 `self.app_settings`도 맞춘다.

### `SettingsPage(QWidget)`

- 제목, 설명, 저장 표시, 카드, 줄(이름 + 입력 칸 + 안내 + 오류)을 만드는 공통 틀. 네 화면이 물려받는다.
- `load(s)`: 칸을 `s` 값으로 채운다. 채우는 동안에는 저장하지 않는다.
- 칸이 바뀌면 바꾼 필드만 `model.update(...)`에 넘기고, 돌려받은 오류를 칸에 표시한다(오류가 없으면 그 칸의 표시를 지운다). 넘기기 전과 뒤의 `model.value`가 다르면 저장된 것이므로 저장 표시를 띄운다.
- `leave()`: 위 "설정 화면을 떠날 때".

### `Sidebar(QWidget)`

- 항목은 직접 그리는 버튼(`NavItem`)이다. 바탕, 빨간 막대, 아이콘, 글자를 `theme.color()`로 그린다. 테마가 바뀌면 다시 그린다.
- '설정' 묶음은 하위 항목을 담은 위젯의 `maximumHeight`를 0 ↔ 내용 높이로 `QPropertyAnimation`(200ms, OutCubic) 한다. 화살표 각도도 같은 시간 동안 0° ↔ 90°.
- 펼침 상태(`expanded`)와 선택(`current`)은 누르는 즉시 바뀌고, 애니메이션은 보이는 것만 맡는다. 테스트는 상태로 확인한다.
- `select(key)`로 코드에서 화면을 바꿀 수 있다(같은 규칙: 설정 화면이면 펼치고, 아니면 접는다).
