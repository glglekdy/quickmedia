# QuickMedia 안드로이드 UI 개편 설계

작성일: 2026-10-29
범위: 안드로이드 앱(`android/`)의 화면 전체. 겉모습(색·글꼴·부품)과 구조(탭·흐름)를 함께 바꾼다.
앞선 설계: [안드로이드 앱 설계](2026-10-29-quickmedia-android-design.md). 거기서 정한 다운로드·업데이트·서명·릴리스는 그대로 둔다.

## 목표

- 기본 Material 화면을 버리고, 시안 A(다크 미디어)의 분위기로 바꾼다. 검은 바탕, 큰 썸네일, 강한 빨강.
- 아래쪽에 아이폰처럼 떠 있는 반투명 알약 메뉴(받기 · 목록 · 설정)를 둔다. 뒤 내용이 흐리게 비친다.
- 링크를 넣으면 다운로드 전에 썸네일·제목 미리보기를 보여 준다.
- 목록에 썸네일, 필터, 다시 받기를 더한다.

시안 파일: `.superpowers/brainstorm/1232-1793277584/content/` 의 `structure.html`(다크), `light-mode.html`(라이트). git 에는 없고, 이 문서가 기준이다.

## 하지 않는 것

- 다운로드 목록을 앱을 껐다 켜도 남기기(앞선 설계와 같다).
- 목록 항목 하나씩 지우기, 밀어서 지우기, 길게 눌러 메뉴.
- 설정의 기본 형식 고르기. 받기 탭에서 고른 형식이 지금처럼 저장된다.
- 다운로드·yt-dlp 인자·업데이트·서명 코드 변경. 예외는 "다시 받기"(`Jobs.retry`) 하나다.
- Material 3 를 완전히 걷어내기. 대화상자·시트·글자 입력칸의 바탕 동작은 Material 3 를 쓰고, 보이는 모양만 새로 입힌다.

## 기술 선택

| 항목 | 값 |
|---|---|
| 떠 있는 메뉴 흐림 | Haze `dev.chrisbanes.haze:haze` **2.0.1**. 안드로이드 12+ 에서 실제 흐림, 10~11 은 흐림 없는 반투명으로 자동 대체 |
| 썸네일 | Coil 3 `io.coil-kt.coil3:coil-compose` · `coil-network-okhttp` **3.6.3**. 메모리·디스크 캐시는 Coil 기본값 |
| 글꼴 | Pretendard **1.3.9** `PretendardVariable.ttf` 하나(가변 굵기, SIL OFL). `res/font/`. 라이선스 문서를 `third_party/pretendard/` 에 둔다. APK 약 3MB 증가 |
| 화면 | Jetpack Compose. 내비게이션 라이브러리는 쓰지 않고 탭 상태 하나로 바꾼다 |

## 화면 구조와 이동

- **탭 세 개**: 받기 · 목록 · 설정. 고른 탭은 `rememberSaveable` 로 화면을 돌려도 남는다. 탭을 바꿀 때는 짧은 페이드로 넘어간다. 지금의 따로 열리는 설정 화면은 없어진다.
- **떠 있는 메뉴(Dock)**: 화면 아래 가운데에 떠 있다. 글자 없이 아이콘만 둔다(이름은 화면 읽기용 설명으로만). 시스템 내비게이션 바 위에 놓인다. 키보드가 올라오면 숨는다. 목록 아이콘에는 대기 중·받는 중 작업 수를 배지로 보인다(0 이면 숨김). 각 화면은 아래쪽 여백을 메뉴 높이만큼 두고, 바탕색으로 서서히 가려지는 그라데이션을 깐다.
- **뒤로가기**: 목록·설정 탭이면 받기 탭으로 간다. 받기 탭이면 시스템 기본(앱 닫기).
- **공유로 들어올 때**: 어느 탭이든 받기 탭으로 바꾸고 링크를 채운다. 링크가 없는 글이면 지금처럼 "링크를 찾지 못했어요".
- **다운로드를 누른 뒤**: 받기 탭에 남고 링크 칸을 비운다. 스낵바 "목록에 넣었어요" + 동작 버튼 "보기"(누르면 목록 탭).
- **업데이트 대화상자**: 앱을 켤 때 한 번 확인하는 흐름은 그대로. 모양만 새 색·글꼴·버튼으로.

## 받기 탭

위에서 아래로: 제목 `Quick`+`Media`(빨강) → yt-dlp 준비 실패 띠(있을 때) → 링크 입력칸 → 미리보기 카드 → 영상/음성 전환 → 화질 칩 → 옵션 줄 → 다운로드 버튼.

### 링크 입력칸

비어 있으면 오른쪽에 "붙여넣기", 차 있으면 ✕(지우기). 키보드의 이동 키는 다운로드와 같다. 링크가 비었는데 다운로드를 누르면 칸 아래 "먼저 링크를 넣어 주세요"(지금과 같다).

### 미리보기

- **언제**: 링크 칸의 글에서 `extractLink` 로 링크가 뽑히면 시작한다. 붙여넣기·공유로 채워지면 바로, 직접 칠 때는 입력이 **600ms** 멈춘 뒤. 뽑힌 링크가 바뀌면 하던 불러오기를 취소하고 새로 시작한다. 링크가 없으면 카드를 숨긴다.
- **yt-dlp 준비**: `App.tools` 가 `Loading` 이면 뼈대 카드로 기다렸다가 `Ready` 가 되면 시작한다. `Failed` 면 미리보기를 하지 않는다(위쪽 띠가 이미 알린다).
- **명령**: `-J --flat-playlist --no-playlist --no-warnings <링크>`. 실행 중 프로세스는 링크가 바뀌거나 화면이 사라지면 끝낸다. `--no-playlist` 라서 `watch?v=…&list=…` 는 그 영상 하나, 재생목록만 가리키는 링크는 재생목록 정보가 나온다.
- **읽는 값**(JSON):
  - 영상: `title`, `uploader`(없으면 `channel`), `duration`(초), `view_count`, `thumbnail`(없으면 `thumbnails` 의 마지막 `url`).
  - 재생목록(`_type == "playlist"`): `title`, `uploader`/`channel`, 개수는 `playlist_count`(없으면 `entries` 길이), 썸네일은 `thumbnails` 마지막 또는 첫 항목의 `thumbnails` 마지막. 없으면 비운다.
  - `title` 이 없으면 실패로 본다.
- **카드 모양**
  - 불러오는 중: 썸네일 자리와 글 두 줄 자리를 회색 뼈대로, 은은하게 반짝인다.
  - 영상: 16:9 썸네일(오른쪽 아래 길이 `3:33`), 제목 최대 2줄, `채널 · 15억 회`.
  - 재생목록: 썸네일 오른쪽 아래 `재생목록 · 12개`, 제목, 채널.
  - 실패: 작은 카드 "영상 정보를 가져오지 못했어요". 다운로드는 그대로 누를 수 있다.
- **기억**: 불러온 결과는 앱 프로세스가 사는 동안 링크별로 기억한다(`Previews`). 같은 링크를 다시 넣으면 다시 부르지 않는다. 실패한 결과는 기억하지 않는다(다음에 다시 시도). 다운로드를 눌렀는데 그 링크의 미리보기가 없거나 실패였으면 그때 다시 불러온다. 목록 카드는 이 기억에서 썸네일·제목을 가져간다. 늦게 끝나도 목록에 채워진다.

### 숫자 표시

- 길이: `59` → `0:59`, `213` → `3:33`, `3723` → `1:02:03`. 없거나 0 이하면 표시하지 않는다.
- 조회수: 1만 미만은 `1,234회`. 1억 미만은 `만` 단위, 10만 미만이면 소수 첫째 자리까지(`.0` 은 뺀다): `12,345` → `1.2만 회`, `123,456` → `12만 회`. 1억 이상은 `억` 단위, 10억 미만이면 소수 첫째 자리: `150,000,000` → `1.5억 회`, `1,500,000,000` → `15억 회`. 소수는 버림. 없으면 조회수 부분을 뺀다.

### 형식 고르기

- 영상/음성 전환: 두 칸짜리 알약. 고른 칸이 밝아진다.
- 칩: 영상이면 최고 · 1080p · 720p · 480p, 음성이면 MP3 · M4A. 고른 칩은 빨강.
- 고르는 즉시 저장한다(`OptionsStore`, 지금과 같다).

### 옵션 줄과 시트

- 줄: 왼쪽에 바꾼 옵션 요약, 없으면 `재생목록 · 메타데이터 · 구간`(흐린 글자). 오른쪽 `옵션 ›`.
- 요약 문구(기본값과 달라진 것만, ` · ` 로 잇기):
  - 재생목록 전체 → `전체 재생목록`, 일부 → `재생목록 1-5,8`(입력값 그대로, 비었으면 `재생목록 일부`)
  - 메타데이터 켬 → `메타데이터`
  - 구간: 시작만 `1:23부터`, 끝만 `1:23까지`, 둘 다 `1:23~2:00`
- 누르면 아래에서 시트(`ModalBottomSheet`)가 올라온다. 안에는 지금의 "옵션 더보기"와 같은 칸: 재생목록(이 영상만 · 전체 · 일부 항목, 일부면 항목 칸), 썸네일·메타데이터 넣기 스위치, 구간 시작·끝 칸과 도움말.
- 다운로드를 눌렀는데 옵션 검사(`YtdlpArgs.validate`)에 걸리면 시트를 열고 틀린 칸에 문구를 띄운다. 문구 규칙은 지금과 같다.

### 다운로드 버튼

빨강 그라데이션, 높이 52dp, 그림자. 누르면 지금과 같은 순서: 링크·옵션 검사 → 알림 권한 한 번 묻기 → `Jobs.add` → `DownloadService.start` → 링크 칸 비우기·포커스 해제 → 스낵바.

## 목록 탭

- **머리**: 제목 `목록`, 오른쪽에 `끝난 항목 지우기`(끝난 게 없으면 흐리게, 누를 수 없음).
- **필터 칩**: `전체 N` · `받는 중 N` · `완료 N` · `실패 N`. 고른 칩은 반전색(다크: 흰 바탕 검은 글자). 받는 중 = 대기·받는 중, 실패 = 실패·취소.
- **묶음**: `전체` 에서만 `받는 중` / `끝남` 두 머리글로 나눈다. 비어 있는 묶음은 머리글도 숨긴다. 순서는 지금처럼 새 작업이 위.
- **카드**: 왼쪽 썸네일(96×56, 모서리 12dp). 미리보기에 썸네일이 없으면 `field` 색 칸에 영상·음성 아이콘. 오른쪽에 제목 1줄(미리보기 제목 → 작업 제목 순), 아래 상태 한 줄.
  - 상태 줄: 대기·받는 중은 `describe(옵션) · 상태`(지금과 같다). 완료는 초록 점 `● 완료 · describe`. 실패·취소는 빨강 점 `● 실패 · 사유` / `● 취소됨`.
  - 받는 중이면 그라데이션 진행 막대. 퍼센트가 0 이면 왔다 갔다 하는 막대.
- **오른쪽 버튼**: 대기·받는 중 ✕(취소), 완료 ▶(열기, 카드 눌러도 열림), 실패·취소 ↻(다시 받기).
- **다시 받기**: `Jobs.retry(id)` 가 실패·취소인 작업을 `QUEUED`·0%·`대기 중`·저장 파일 없음으로 되돌리고 `true`. 그 밖의 상태면 아무것도 하지 않고 `false`. `true` 면 `DownloadService.start`. 그 링크의 미리보기가 없으면 다시 불러온다. 목록에서 자리는 그대로다.
- **비었을 때**(고른 필터에 항목이 없을 때 포함): 가운데 아이콘과 `아직 받은 게 없어요`(필터가 전체가 아니면 `해당하는 항목이 없어요`), 전체일 때만 `받기로 가기` 버튼.

## 설정 탭

- **위쪽 카드**(빨강 기운 그라데이션): `Quick`+`Media` 와 버전(`BuildConfig.VERSION_NAME`), 상태 한 줄, `업데이트 확인` 버튼.
  - 상태: 확인 전 `업데이트를 확인해 보세요`, 확인 중 `확인하는 중…`, 최신 `최신 버전이에요`, 새 버전 `새 버전 1.2.0 이 있어요`(누르면 업데이트 대화상자), 실패 `UpdateException` 문구.
  - 동작은 지금 `SettingsScreen` 의 업데이트 확인과 같다.
- **묶음 1**: `yt-dlp` + 버전 + `갱신`(지금 기능), `저장 위치` + `다운로드/QuickMedia` + `열기`(`DownloadManager.ACTION_VIEW_DOWNLOADS`, 열 앱이 없으면 스낵바 `이 파일을 열 수 있는 앱이 없어요`).
- **묶음 2**: `GitHub에서 보기` ›(브라우저로 `https://github.com/glglekdy/quickmedia`).

## 버전

이 개편은 아직 태그를 달지 않은 **v1.1.0** 에 함께 넣는다. 안드로이드 앱의 첫 공개가 새 화면으로 나간다. 릴리스 노트(`release-notes/v1.1.0.md`)의 기능 설명은 그대로 맞고, 미리보기·다시 받기 한 줄만 더한다.

## 시험

- **단위 테스트(JVM)**
  - `Preview.parse`: 영상, 재생목록(`playlist_count` 있음 / `entries` 만 있음), `thumbnail` 없고 `thumbnails` 만 있음, `uploader` 없고 `channel` 만 있음, `title` 없음 → null, 깨진 JSON → null.
  - `formatDuration`: 0·음수·null → null, 59, 213, 3723.
  - `formatViews`: 0, 1234, 9999, 12345, 99999, 123456, 99,999,999, 150,000,000, 1,500,000,000, null.
  - `JobFilter`: 필터별 항목, 개수, 전체의 두 묶음, 빈 묶음 숨김.
  - `Jobs.retry`: 실패·취소 → 대기·0%·저장 비움·true, 받는 중·완료 → 그대로·false.
  - `optionsSummary`: 기본값 → null, 각 옵션과 조합.
- **에뮬레이터 확인**(`Pixel_10_Pro_XL`, API 37)
  - 다크·라이트에서 세 탭 스크린샷.
  - 공유로 링크 받기 → 미리보기 → 다운로드 → 스낵바 '보기' → 목록 진행 → 완료 ▶.
  - 없는 영상 링크로 실패 → ↻ 다시 받기. 받는 중 ✕ 취소.
  - 키보드가 올라오면 메뉴가 숨는지, 화면을 돌려도 탭이 남는지.
- **안드로이드 10 확인**: API 29 에뮬레이터 이미지로 메뉴가 흐림 없는 반투명으로 보이고 앱이 죽지 않는지.
