## 영어 지원

- 앱을 영어로 쓸 수 있어요. '설정 → 일반'에서 한국어와 English 중에 고르면 바로 바뀌어요.
- 처음 켤 때는 Windows 표시 언어를 따라가요. 한국어 Windows면 한국어로, 그 밖에는 영어로 켜져요.

## 더 부드러운 화면

- 다운로드를 시작하면 받기 버튼에서 동그라미가 나와 새 카드로 펼쳐져요.
- 화면을 오갈 때 옆으로 밀리며 바뀌고, 프리셋 · 세부 옵션 판과 알림도 부드럽게 나타났다 사라져요.
- 움직임이 끊기지 않게 화면을 그리는 속도를 높였어요.

## 프리셋

- 켜져 있는 프리셋을 한 번 더 누르면 풀려요.
- 프리셋을 적용하거나 풀면 링크 칸 위에 작은 알림이 떠요.
- 바꿔 둔 세부 옵션이 있으면 '세부 옵션' 단추 둘레가 붉게 빛나서 한눈에 보여요.

## 달라진 점

- 설정 화면에서도 받는 중인 영상 수와 다 받은 영상 수를 '다운로드' 단추 옆에서 볼 수 있어요.
- 설정에 '일반' 탭이 생겼어요. 설정을 처음 열면 이 탭이 먼저 보여요.
- 화면의 문구를 더 짧게 다듬었고, 설정 화면 제목 아래의 설명 줄을 없앴어요.
