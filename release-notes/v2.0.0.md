## 더 가벼워졌어요

- 앱을 처음부터 다시 만들었어요. 더 빨리 켜지고 메모리를 훨씬 덜 써요. 설치 용량도 줄었어요.
- 설치 파일이 훨씬 작아졌어요. 변환 도구(ffmpeg)는 PC에 이미 있으면 그걸 쓰고, 없을 때만 처음 켤 때 한 번 받아요. 받는 동안 걸어 둔 다운로드는 끝나면 바로 시작해요.
- 기능은 그대로예요. 저장 위치, 설정, 이미 받은 영상 기록도 그대로 남아요.

## 새 화면

- 링크 칸과 메뉴를 아래로 모아 목록을 넓게 볼 수 있어요. 링크 칸을 누르면 형식 · 프리셋 · 세부 옵션이 펼쳐지고, 빈 곳을 누르면 다시 접혀요.
- 오른쪽 아래의 '다운로드 · 설정'으로 화면을 오가요. 설정을 누르면 링크 칸이 작게 줄고 메뉴가 펼쳐져 로그인 · 네트워크 · 파일 · 고급 · 업데이트가 나와요.

## 새 기능

- '설정 → 업데이트'에서 yt-dlp를 갱신할 수 있어요. 사이트가 바뀌어 영상이 받아지지 않을 때 앱 새 버전을 기다리지 않아도 돼요.

- 자주 쓰는 세부 옵션을 프리셋으로 저장할 수 있어요. 링크 칸을 펼치면 나오는 '프리셋'을 눌러 이름을 붙여 저장하고, 다음부터는 골라 쓰면 돼요.
- 받는 동안 화면 아래에서 빛이 번져서 다운로드 중인지 한눈에 보여요.

## 달라진 점

- 저장 위치는 '설정 → 파일'로 옮겼어요.

- 재생목록을 같은 폴더에 다시 받으면 이미 있는 영상은 새로 받지 않고 건너뛰어요. 예전에는 '제목 (1)'처럼 번호를 붙여 한 번 더 받았어요. 링크 하나를 다시 받을 때는 예전처럼 번호를 붙여 새로 받아요.
- 고급 설정의 yt-dlp 옵션에 주소를 값으로 넣을 때는 `--referer=https://…`처럼 `=`로 붙여 써 주세요.

안드로이드 앱은 이번 버전부터 지원하지 않아요. 설치해 둔 앱은 계속 쓸 수 있지만 새 버전은 나오지 않아요.
