## 더 가벼워졌어요

- 앱을 처음부터 다시 만들었어요. 더 빨리 켜지고 메모리를 훨씬 덜 써요. 설치 용량도 줄었어요.
- 설치 파일이 훨씬 작아졌어요. 변환 도구(ffmpeg)는 PC에 이미 있으면 그걸 쓰고, 없을 때만 처음 켤 때 한 번 받아요. 받는 동안 걸어 둔 다운로드는 끝나면 바로 시작해요.
- 화면과 기능은 그대로예요. 저장 위치, 설정, 이미 받은 영상 기록도 그대로 남아요.

## 새 기능

- 메뉴의 '업데이트' 화면에서 yt-dlp를 갱신할 수 있어요. 사이트가 바뀌어 영상이 받아지지 않을 때 앱 새 버전을 기다리지 않아도 돼요.

## 달라진 점

- 재생목록을 같은 폴더에 다시 받으면 이미 있는 영상은 새로 받지 않고 건너뛰어요. 예전에는 '제목 (1)'처럼 번호를 붙여 한 번 더 받았어요. 링크 하나를 다시 받을 때는 예전처럼 번호를 붙여 새로 받아요.
- 고급 설정의 yt-dlp 옵션에 주소를 값으로 넣을 때는 `--referer=https://…`처럼 `=`로 붙여 써 주세요.

안드로이드 앱은 이번 버전부터 지원하지 않아요. 설치해 둔 앱은 계속 쓸 수 있지만 새 버전은 나오지 않아요.
